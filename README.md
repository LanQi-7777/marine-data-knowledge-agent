# Agent-assisted Marine Data Knowledge Framework

This repository provides the prototype implementation of an agent-assisted knowledge framework for multidisciplinary marine data discovery, evidence retrieval, dataset comparison, and reuse-oriented decision support.

## Related paper

This repository accompanies the manuscript:

**Multidisciplinary marine data resources for data-driven research: a cross-domain data review, comparative assessment, and agent-assisted knowledge framework**

**Authors:** Yuqi Shao, Zhensheng Shi, and Haiyong Zheng
**Journal:** Earth System Science Data
**Manuscript type:** Data review article
**Status:** Submitted manuscript

The paper reviews and compares representative marine data resources across major marine domains, including marine meteorology and climate, marine geology and bathymetry, ocean observation and biogeochemical profiles, marine biodiversity, marine ecological environment and pollution, fisheries and aquaculture, and supporting geospatial and integrated marine data infrastructures. It proposes a comparative assessment framework covering spatiotemporal coverage, resolution, data quality, uncertainty information, metadata completeness, accessibility, interoperability, and deep-learning readiness.

This repository provides the code, configuration files, prompt templates, curated catalogue metadata, and example workflow for the agent-assisted marine data knowledge framework described in the manuscript. The framework is designed to support evidence retrieval, dataset comparison, answer generation, quality checking, and reuse-oriented marine data discovery.

## Repository contents

* `workflows/`: Dify workflow files for the agent-assisted marine data knowledge framework
* `prompts/`: prompt templates for evidence retrieval, dataset comparison, answer generation, and quality checking
* `catalog/`: curated marine data catalogue, evaluation indicators, and supporting metadata
* `examples/`: example queries and use cases for dataset discovery and comparison, if available

## Data and copyright statement

This repository does not redistribute third-party marine data products. Users should access the original data products from the official providers listed in the manuscript and catalogue files. The catalogue and assessment materials provided here are derived review-support resources intended to help readers inspect, compare, and reuse the information summarized in the manuscript.

API keys, proprietary model weights, private credentials, and third-party copyrighted source data are not included.
